Introdução inteligente de informação clínica

1 · Documento

Nenhum ficheiro selecionado.

Os ficheiros são tratados localmente. PDF: leitura automática ainda não disponível. OCR de imagem: apenas se suportado pelo navegador.

2 · Revisão clínica

Os campos são candidatos heurísticos, não resultados validados. Confronte com o documento original. A lista de linhas não classificadas pode conter informação relevante.

3 · Texto para o processo clínico

TRANSCRIÇÃO PARCIAL — COMPLETUDE NÃO CERTIFICADA

Privacidade e limitações

Sem envio de documentos para serviços externos pelo código da aplicação. Não há armazenamento persistente de dados clínicos nem integração com o processo clínico. Não foi efetuada validação clínica. A publicação num serviço externo exige avaliar também a política do alojamento. Não introduza dados identificáveis de doentes durante os testes.
